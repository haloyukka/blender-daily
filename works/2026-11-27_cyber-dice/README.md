# サイバーなサイコロ / Cyber Dice

![render](render.png)

| 項目 | 内容 |
|---|---|
| 日付 | 2026-11-27 |
| Blender | 5.3（4.x でも動作する想定） |
| エンジン | Cycles / 128 samples / 1080×1350 |
| タグ | cyber, neon, emission, procedural, dice |

## 概要

ネオンが光るサイバーなサイコロ。ガンメタの本体に、6面それぞれ黒い強化プレートをはめ込み、目と回路パターンを光らせた。奥にもう1個置いて、ネオングリッドの床でまとめている。

- プレートの隙間からバイオレットがにじむシーム発光
- 目（ピップ）は 穴あけ → 発光ディスク → アイリスリング → 金属ベゼル の4層構造
- 目から伸びる回路パターン（45度配線・ビア・チップ部品）を、面ごとに乱数で自動生成
- 四隅のヘックスネジ、面番号の刻印（`D6 // 05` など）
- 1の目だけマゼンタの大きなレンズにし、外周リングと照準の目盛りをつけた
- 床（ホリゾント）・ライト・カメラ・ブルーム（コンポジット）まで自動構築

## 再現方法

Blender の Scripting タブで `cyber_dice.py` を開いて「Run Script」。
コマンドラインから画像まで出す場合:

```
blender --background --python cyber_dice.py -- --render render.png
```

## 調整できるパラメータ

| 変数 | 意味 | 既定値 |
|---|---|---|
| `PIP_COLOR` | 目の発光色 | シアン |
| `ONE_COLOR` | 1の目・ビアの発光色 | マゼンタ |
| `SEAM_COLOR` | プレート隙間の発光色 | バイオレット |
| `TRACE_COLOR` | 回路パターンの発光色 | シアン |
| `GRID_COLOR` | 床グリッドの発光色 | バイオレット |
| `GLOW` | 発光の強さ（全体倍率） | 1.0 |
| `TRACE_COUNT` | 1面あたりの回路パターン本数 | 14 |
| `SEED` | 回路パターンの乱数シード（変えると配線が変わる） | 27 |
| `DIE_YAW` | メインのサイコロの向き（度） | -16 |
| `BLOOM` | コンポジットでブルームをかける | True |
| `TURNTABLE` | 120フレームの回転アニメにする | False |

## メモ

- 回路パターンは 45度刻みの8方向でランダムウォークし、格子（0.022刻み）の占有セルで線同士・目・ネジ・刻印との干渉を避けている
- 目の穴は円柱をまとめた1オブジェクトでブーリアン（Exact）し、評価済みメッシュに置き換えてから角に Bevel をかけた
- ブルームは Blender 5.x でコンポジットの仕組みが変わった（`scene.compositing_node_group` ＋ Group Output、Glare の種類はソケット入力）。4.x の `scene.node_tree` 方式と両方に対応
- 最初はサイコロの向きとカメラの方位がそろって正面しか見えなかった。向きを -16° にして3面が見えるようにした
- 黒いプレートはコート（クリアコート）付きなのでキーライトが映り込みやすい。キーは弱く大きくして白飛びを抑えた
